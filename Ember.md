# Ember: Habit And Task Manager

## Project Description

Ember is a mobile application centered around managing habits and task, and comes with an optional accountability system for users, a dynamic streak system, and monthly heatmaps that show a user their performance throughout the month.

The main idea behind Ember is to provide a habit and task manager, similar to many popular ones today, but with the ability to have more flexibility for users with more chaotic schedules, as well as an optional ability to make use of an accountability partner, which in research has shown to improve consistency. This is primarily targeted and college students and professors who often have changing schedules throughout the year, but it would also work for normal schedules as well. This will be done through more dynamic task and habit managment, such as having weekly or even monthly goals, which when paired with the momentum system that will be used for the streaks, will allow users to manage time in for task throughout the week or month instead of just daily task, and if they miss a goal, doesn't immediately punish them, but instead pushes them to aim for a 100% consistency instead of lowering it further.
